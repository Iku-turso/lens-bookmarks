# Changelog

What changed in each version of this extension, newest first.

## 0.1.0

- Added a **Bookmarks** item to the navigator, holding your named bookmarks in order of name.
- Added bookmarks of a cluster's lists (Pods, Deployments, Nodes, …), from the **Bookmark…** submenu of a cluster's right-click menu (named after the cluster), and from the right-click menu of a list under a cluster in the navigator.
- Added **Bookmark…** to the right-click menu of Kubernetes resources, named after the resource and its cluster.
- Added bookmarks for arbitrary URLs, from the Bookmarks item's menu and the command palette command **Bookmarks: Bookmark a URL**.
- Added renaming and removing bookmarks from their right-click menu.
- Added icons for what each bookmark points at, in the colour of the bookmark's cluster.
- Added bookmarks to the hotbar: **Add to hotbar** and **Remove from hotbar** in a bookmark's right-click menu.
